# Anakin Name Generator

## Author

Ron Mutunga

## Description

Akan Name Generator is a web application that calculates the day of the week you were born and assigns a name based on your gender and the day of the week. 

## Features 

- Smooth scrolling
- Name generator
- Birthday and Gender Inputs
- Calculates your birthday into the day of the week


## Technologies used

 - HTML5
 - CSS3
 - JavaScript
 - Git
 - GitHub

## Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/ronnmtu/Anakin-Project.git
   ```
2. Open the project folder in your code editor.
3. Open `index.html` in a browser to run the app.
4. Optionally, use a live server extension or a local web server for the best experience.
